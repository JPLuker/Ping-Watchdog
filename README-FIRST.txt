PING WATCHDOG FOR WINDOWS

First monitor
1. Run PingWatchdog-win-Setup.exe, or extract the portable ZIP and open
   PingWatchdog.exe.
2. Choose Add hosts > Save hosts to a site. Enter a hostname or IP address.
   For several hosts, paste one per line.
3. Select a Site or type a new site name. Check the preview, then click
   Add hosts to save the selected rows.
4. Click Start monitoring. Select All sites or a single site. Turn on
   Show ping log to see replies and missed attempts.

Working with hosts
- Map shows hosts by site. List lets you search, filter and edit them.
  Right-click a map host and choose Edit in host list to select it in List.
  Ctrl+click selects individual rows. Shift+click selects a range. Right-click
  the selection for bulk actions, or press Shift+F10. F2 renames a host.
  Ctrl+Z undoes a List edit while Undo is available (eight seconds).
- Add hosts > Monitor temporarily starts a temporary session. In List,
  right-click the selection > Keep in a site to save temporary hosts.
- Right-click a host to snooze it
  for one hour. Its probes, live log and
  active alerts pause. Resume monitoring now ends the snooze early.
- Mark a host as priority to repeat outage and recovery alarms every
  15 seconds until acknowledged. Set the sound in Settings > Notifications.
- Open Outage history (Ctrl+H) to filter or export events. Wallboard opens
  the fullscreen display. Esc or F11 returns to the main window.

Settings, backups and updates
- Stop monitoring before changing timing or outage thresholds. Save changes
  applies your Settings draft.
- Settings > Data and storage > Create backup saves hosts, preferences,
  snoozes and history. Restore backup replaces active data and restarts the
  app. Stop monitoring and close other copies before restoring.
- Portable copies use per-user storage by default. Enable portable storage
  in Data and storage to save beside the portable application.
- Check for updates is in the sidebar and Settings > Updates. Automatic
  checks run at most daily when enabled. Restart now applies a downloaded
  update. Later defers it. A failed restart offers Retry restart.

# Windows changelog

Selected changes in recent Windows releases. [Full release history](https://github.com/JPLuker/Ping-Watchdog/releases)

## 1.19.27

- Kept Ping activity below both Map and List in the same shared pane.
- Removed the Host actions button. Right-click selected hosts for individual or bulk actions.
- Added Shift+F10 and the Menu key for host actions, and Escape to clear selection.

## 1.19.25

- Grouped single-host and bulk commands under Host actions to leave more room for the list.
- Removed the redundant idle map heading and its empty space.
- Softened the update popup border and clipped its corners on first display.

## 1.19.24

- Kept List rows and selection steady while ping results update.
- Added visible host actions in List and an Edit in host list action from the map.
- Grouped saved and temporary host adding under Add hosts.
- Separated the update popup from the map and removed the redundant Sites heading.

## 1.19.23

- Added packaged third-party notices with access from Settings → About.

## 1.19.22

- Updated the packaged quick start for the current Windows interface and updater.

## 1.19.21

- Added Retry restart and Later when a downloaded update fails to restart the app.

## 1.19.20

- Fixed missing Monitoring and History settings labels and horizontal scrolling at minimum window size. Appearance and History dropdowns now use the selected theme.

## 1.19.18

- Improved initial focus and keyboard navigation in supporting windows. Long startup recovery errors remain scrollable and diagnostic-copy failures have space below the actions.

## 1.19.16

- Separated Quick Add and Quick Monitor input, destination and preview. Fixed pasted lines and revised the label, site-name and folder dialogs.

## Earlier 1.19 releases

- Added priority alarms with acknowledgment, List editing with Undo, daily update checks and explicit restart confirmation. Added checksums to Windows downloads.

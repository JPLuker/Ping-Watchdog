# Ping Watchdog {version} for Linux

- Same look and features as the Windows app: Quiet Precision in light and dark, the connected map, and the List with search, filters, multi-select and Undo.
- Right-click any host for its actions: edit, group, snooze, priority, disable, move, monitoring, remove.
- Priority hosts ring until you acknowledge them.
- Quick Add and Quick Monitor take pasted rows, CSV, CIDR blocks and ranges.
- Settings are staged with Save changes. Backups, restore and Delete saved data are in Data and storage.
- New packages: .deb, .rpm, .tar.gz and Flatpak, next to the self-updating AppImage.

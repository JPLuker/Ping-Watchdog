# Support and maintenance

Issues are monitored on GitHub. Use **Settings → About → Report an issue…** or the issue chooser. For security problems, follow the private reporting instructions. [Issues](https://github.com/JPLuker/Ping-Watchdog/issues/new/choose) · [Security](SECURITY.md)

For a Windows bug, include the app version from About, Windows version, package type, and the shortest steps that reproduce the problem. A screenshot helps with layout or prompt issues. Replace real site names, host addresses and usernames with examples.

The Windows feature set is frozen while the maintenance candidate is tested. Fixes focus on crashes, data loss, incorrect monitoring and alerts, broken installation or updates, security, compatibility and accessibility. A feature request records a use case without committing it to a release. The Linux beta is tracked separately. [Windows roadmap](ROADMAP.md) · [Linux guide](README-LINUX.md)

After final acceptance, the maintenance target is a weekly issue review and acknowledgment within seven days. Security and data-loss reports take priority. Fixes ship in the current Windows release. [Windows releases](https://github.com/JPLuker/Ping-Watchdog/releases/latest)

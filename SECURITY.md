# Report a security problem

Use the newest official release for your platform when checking whether a problem still affects Ping Watchdog. Security fixes target the current Windows release and the current Linux release.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/JPLuker/Ping-Watchdog/security/advisories/new). The public Security page was verified to offer **Report a vulnerability** on 2026-11-13. Do not put vulnerability details in public issues.

In the private report, include the affected version, platform and package type, impact and steps to reproduce with sample hosts. Redact real network inventory, usernames and credentials. The target for acknowledging a report is seven days.

# Report a security problem

Use the newest official Windows release when checking whether a problem still affects Ping Watchdog. Security fixes target the current Windows release. The Linux beta has a separate release track.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/JPLuker/Ping-Watchdog/security/advisories/new). The public Security page was verified to offer **Report a vulnerability** on 2026-11-13. Do not put vulnerability details in public issues.

In the private report, include the affected version, installer or portable package, impact and steps to reproduce with sample hosts. Redact real network inventory, usernames and credentials. The target for acknowledging a report is seven days.

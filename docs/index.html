Getting started

Your first ping.

Add a host and start monitoring
  1. Choose Add hosts and enter an IP address or hostname.
  2. Select a site or type a new site name. Review the preview and click Add hosts.
  3. Click Start monitoring. Turn on Show ping log to see individual replies.
Where is my data stored?

Inventory, settings and history are stored on your PC. Monitoring sends pings to your targets, and update checks contact GitHub. Network and privacy details
